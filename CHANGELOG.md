# Changelog

## v0.7.1
- **Tools → Screenshot (in 5 seconds)** saves the whole screen as a PNG in a `Screenshots` folder next to MeshChatCE.exe. The delay lets you switch to the Nodes or Map screen first.

## v0.7
- Rename your node (long and short name) from the phone; the new name is sent to the mesh straight away
- **Send my info** (Tools) and **Swap info** (Nodes → Actions) to share names and encryption keys — fixes "missing key" DM errors
- Plain-English delivery errors (e.g. error 39 → "missing their key - try again in a minute")
- Nodes list sortable by tapping a column heading (tap again to reverse)

## v0.6.1
- Sending a message always scrolls to the newest message
- Switching conversations opens at the newest message
- "▼ New message" bar when messages arrive while you're scrolled up

## v0.6
- Texting-style chat bubbles (sent on the right, received on the left), date separators, tap a bubble for details
- Classic list layout still available
- Light, Dark and Night (red) colour themes; Tahoma or Courier New font
- Fixed: "Open MeshChatCE" link in the background pop-up

## v0.5.1
- Waits for Wi-Fi before connecting (fixes the phone not joining Wi-Fi when MeshChatCE starts at boot)

## v0.5
- Radar-style map (no internet needed), tap a node for details, zoom
- Background pop-up and blinking notification light
- Keep-awake option (keeps Wi-Fi up with the screen off)
- Settings screen; message search; app icon

## v0.4
- Renamed to MeshChatCE
- Bluetooth GPS with on/off switch; position sharing; distance and direction to nodes
- Range log (CSV), mesh stats, quick replies, sound and vibration, text size

## v0.3
- Nodes screen (signal, hops, battery), favorites, traceroute

## v0.2
- All channels, direct messages, delivery status

## v0.1
- First native version: connect, show and send messages on the primary channel
